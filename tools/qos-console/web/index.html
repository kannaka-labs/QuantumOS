QuantumOS Console

staging · real KVM microVM

Each boot starts a fresh QuantumOS virtual machine on Firecracker, with no disk and no network. It is at the qsh> prompt within a second or two. You get ten minutes; the machine is deleted when you close the page or the timer runs out. Nothing you type is logged.
