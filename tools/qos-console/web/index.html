QuantumOS Console

staging · real KVM microVM

Each boot starts a fresh QuantumOS virtual machine on Firecracker, with a small blank disk and no network. It is at the qsh> prompt within a second or two. You get ten minutes; the machine is deleted when you close the page or the timer runs out, unless you keep it. Nothing you type is logged.

idle 10:00
Your machine key:

This key is shown once and is the only way back to this machine. Copy it now. Type sync to save; when you come back with the key you get what you last synced. A machine that was never synced is not kept.

Kept machines are deleted after 7 days without use. They are stored on our server without encryption, so the operator can read them: don't keep anything private.

Try help, ls /, imprint a cat sat on the mat then recall a cxt sxt on thx mat. The page counts page loads and Boot presses, with no cookies and no addresses kept: visitor counts and timings.
